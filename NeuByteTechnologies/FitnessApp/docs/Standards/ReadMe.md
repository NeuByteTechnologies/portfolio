## Purpose
The **Standards** directory contains all governance documents that define how NeuByte documentation is structured, formatted, versioned, and visually represented. These standards ensure consistency, reviewer‑safety, and professional presentation across the entire FitnessApp documentation set.

This folder acts as the authoritative reference for:
- Versioning rules  
- Visual grammar  
- Formatting conventions  
- Documentation metadata  
- Diagramming standards  
- Naming conventions (future)  
- Any additional governance artifacts  

---

## Contents
The following standards are maintained in this directory:

- **Versioning Policy**  
  Defines how version numbers are assigned, incremented, displayed, and synchronized across Markdown, Word, Excel, and diagram artifacts.

- **Visual Grammar Specification**  
  Defines NeuByte’s diagramming rules, including color palette, stroke widths, spacing, typography, and footer bar conventions.

Additional standards may be added as the documentation system evolves.

---

## Scope
These standards apply to all documentation artifacts in the FitnessApp portfolio, including:

- Markdown (`*.md`)
- Word documents (`*.docx`)
- Excel documents (`*.xlsx`)
- Diagrams (`*.png`, `*.svg`, `*.drawio`)
- Supporting metadata files

---

## Usage
All contributors must follow the standards in this directory when creating or updating documentation.  
Before submitting or publishing any deliverable, verify:

1. Version number is correct  
2. Revision History is updated  
3. Footer metadata matches the latest version  
4. Visual grammar rules are applied to all diagrams  
5. Formatting and structure follow the standards

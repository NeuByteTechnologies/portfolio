# Workflows Overview

This folder contains standardized operational workflows used across the NeuByte documentation and diagramming ecosystem. Each workflow defines a repeatable, reviewer‑safe process that supports consistency, quality, and efficiency across all documentation and asset‑creation tasks.

## Purpose of This Folder

The /docs/workflows/ directory serves as a centralized location for:

- Process documentation
- Repeatable operational steps
- Diagramming and stencil‑creation procedures
- Asset preparation and export workflows
- Supporting materials for documentation sprints

These workflows ensure that all contributors follow the same conventions and visual grammar, reducing rework and maintaining a unified documentation standard.

## Available Workflows

Below is the current list of workflows maintained in this folder.

### 1. PNG → SVG Workflow

**File:** png-to-svg.md

Describes the complete process for converting PNG assets into clean, minimal‑node SVG files using Vectorizer.AI and Inkscape. Ensures all vector assets meet NeuByte visual grammar and stencil‑system requirements.

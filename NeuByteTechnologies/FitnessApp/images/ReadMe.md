# Images

This folder contains supporting images used by the UI Specification documents.  
Images are limited to sample screen mockups, wireframe exports, and other visual references that accompany the UI Spec Markdown files.  
All images are stored separately to keep UI Spec documents clean, lightweight, and GitHub‑native.

---

## Purpose of This Folder
- Provide a centralized location for all UI Spec–related images.
- Keep Markdown files lightweight by referencing images instead of embedding large assets.
- Maintain a clean separation between documentation content and visual artifacts.
- Support reviewer‑safe navigation by organizing images outside the main UI Spec files.

---

## What This Folder Includes
- Sample UI screen images  
- Wireframe exports  
- Component mockups (if applicable)  
- Visual references used in UI Specifications  

Images are named to match their corresponding UI Spec file.

# Web Application (Front‑End)

This folder is reserved for the front‑end implementation of the FitnessApp project.  
It will contain the source code, assets, and configuration files for the web client once development begins.  
At this stage, the folder serves as a placeholder to show where the UI implementation will live in the final project structure.

---

## Purpose of This Folder
- Provide a dedicated location for all front‑end code and assets.
- Separate implementation from documentation to maintain a clean repository structure.
- Support future development using a modern web stack (e.g., React, Tailwind, ShadCN, Vite).
- Align with the architecture and UI Specifications defined in the documentation.

---

## What This Folder Will Contain
Once development begins, this folder will include:

- **Source Code (`/src`)**  
  Components, pages, hooks, services, and utilities.

- **Assets (`/public` or `/assets`)**  
  Icons, logos, static images (not UI Spec images).

- **Configuration Files**  
  `package.json`, `vite.config.js`, `tsconfig.json`, environment files, etc.

- **Routing & State Management**  
  React Router, Zustand, or other chosen libraries.

- **API Integration Layer**  
  Fetch/axios wrappers aligned with the API Contracts.

---

## What This Folder Does *Not* Contain
- UI Spec images (those remain in `/images`)  
- Documentation (BRDs, FS, UI Specs, API Contracts, etc.)  
- Architecture diagrams  
- Test
